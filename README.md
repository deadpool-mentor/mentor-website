# 정수멘토 홈페이지 로컬 시안

Node.js 24에서 `npm start`를 실행한 뒤 `http://127.0.0.1:8123/`을 엽니다.

상담 신청과 안내 글·후기는 로컬 SQLite 데이터베이스 `data/consultations.sqlite`에 저장됩니다. 관리 화면은 `http://127.0.0.1:8123/admin`이며, 서버 시작 시 출력되는 관리 암호를 입력합니다. 관리 화면 아래쪽에서 안내 글과 후기를 직접 작성·수정·삭제할 수 있습니다. 서버를 다시 시작하면 암호가 새로 생성됩니다. 고정 암호를 사용하려면 실행 전에 `MENTOR_ADMIN_PASSWORD` 환경 변수를 설정하세요.

정적 HTML 파일만 별도로 배포하면 상담 신청과 글 관리 기능은 동작하지 않습니다. 실제 공개 절차는 [운영-배포-가이드.md](./운영-배포-가이드.md)를 참고하세요.
