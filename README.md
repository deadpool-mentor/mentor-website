# 정수멘토 홈페이지 로컬 시안

Node.js 24에서 `npm install` 후 `npm start`를 실행한 뒤 `http://127.0.0.1:8123/`을 엽니다.

상담 신청과 안내 글·후기는 로컬 SQLite 데이터베이스 `data/consultations.sqlite`에 저장되고, 글에 올린 이미지는 `data/uploads`에 저장됩니다. 관리 화면은 `http://127.0.0.1:8123/admin`이며, 서버 시작 시 출력되는 관리 암호를 입력합니다. 관리 화면 아래쪽에서 안내 글과 후기를 서식·HTML·이미지를 넣어 작성·수정·삭제할 수 있습니다. 서버를 다시 시작하면 암호가 새로 생성됩니다. 고정 암호를 사용하려면 실행 전에 `MENTOR_ADMIN_PASSWORD` 환경 변수를 설정하세요.

글은 `/posts/글번호` 또는 `/reviews/글번호`에서 각각 열립니다. `robots.txt`와 `sitemap.xml`이 자동 생성되며 예시 글은 검색 대상에서 제외됩니다. 게시 후 Google Search Console에서 사이트를 등록하고 사이트맵을 제출할 수 있습니다. 검색 반영은 보장되지 않습니다.

정적 HTML 파일만 별도로 배포하면 상담 신청과 글 관리 기능은 동작하지 않습니다. 실제 공개 절차는 [운영-배포-가이드.md](./운영-배포-가이드.md)를 참고하세요.
